About me

I'm a third-year BSc Information Technology student at North-West University, working toward a role as a Junior .NET / C# Software Developer. My academic work spans a cross-platform mobile app, a full-stack booking system, and a systems analysis project — the common thread is that I like modelling a problem properly before I start writing code.

I write code with the next reader in mind, and back that up with a working grasp of secure coding practice, database normalization, and the OWASP Top 10.
